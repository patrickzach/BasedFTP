A FEW GOOD QUESTIONS

Let's clear things up.

Free and open source? Really?+

Absolutely. BasedFTP is free and open source. You can explore the code, understand how it works, and make it your own. No subscription, advertising, telemetry, or account required.

What do I need to run it?+

A Mac running macOS 14 or later and a server with FTP, FTPS, or SFTP access. BasedFTP is a native Mac app built with SwiftUI and AppKit.

Which protocols does it support?+

BasedFTP supports FTP, FTPS, and SFTP. For SFTP, it uses the OpenSSH included with macOS, with support for passwords, SSH keys, SSH agent, and your existing SSH configuration.

Can I edit files on my server?+

Yes. Open a remote file in your preferred editor and save to upload your changes automatically. Edits overwrite the remote content, including changes made on the server in the meantime, so coordinate when working on shared files.

Is it ready for production?+

BasedFTP is an active development build, not yet a fully production-hardened release. Core builds and SSH integration tests have been checked, but broader hardware and authentication testing is still ongoing. Notarization and App Store availability are not currently offered.

How are my passwords stored?+

BasedFTP integrates directly with macOS Keychain to store and retrieve saved connection passwords. Your credentials stay in the Mac’s built-in password storage, without a separate BasedFTP account or password vault.
